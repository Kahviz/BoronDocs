# Why you should trust BoronEngine

1. The code is open-sourced and you can download it at [github](https://github.com/Kahviz/BoronGameEngine)
2. We have people who are using BoronEngine and trusting it

# Reporting a Vulnerability
If you discover a potential security vulnerability in BoronEngine, please report it privately.
- Dont publish the vulnerability on github issues
- Include steps to reproduce the vulnerability
- Include relevant logs, screenshots, or proof-of-concept code if possible.
