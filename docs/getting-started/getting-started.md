# Getting Started

To run BoronEngine, you have two options:

1. **Download the latest release**

   Download the pre-built BoronEngine executable from GitHub Releases.

   [Learn how to download and run BoronEngine](download.md)

2. **Build BoronEngine from source**

   Download the source code, configure the project with CMake, build it, and then run BoronEngine.

   Follow these steps:

   1. [Check the build requirements](requirements.md)
   2. [Download and build the source code](source-code.md)
